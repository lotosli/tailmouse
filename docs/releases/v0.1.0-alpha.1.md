# TailMouse v0.1.0-alpha.1

This first public preview provides native downloads for Linux, macOS and Windows on x64 and ARM64. Guests use [tailmouse.com](https://tailmouse.com) in a browser. No account, native guest installation or separately installed Tailcat is required.

## Included

- `cli`: share a terminal with host-owned access and read-only controls.
- `web`: preview a configured local HTTP service, including supported WebSocket traffic.
- `receive`: receive hash-verified files into an existing Linux/macOS folder without overwriting existing files.
- `dev`: combine at least two resources in one browser workspace.
- Escape and legacy protected Leash remain available.

Port-only targets use `127.0.0.1` on the host. Sessions and transfers retain approval, expiry, quotas, cancellation and revocation checks. The release uses Resource protocol 2 and Tailcat `52fbad323e9d352f1febb623e0975368e9a8cbdd`.

## Downloads

Choose one of the six `tailmouse_0.1.0-alpha.1_OS_ARCH` archives. macOS/Linux use `.tar.gz`; Windows uses `.zip`. Each includes the executable, README, Apache-2.0 license, project notice and third-party notices. No installer or system service is added.

`SHA256SUMS` covers the published assets. Each archive has a corresponding CycloneDX 1.7 `.cdx.json` SBOM. `release-manifest.json` binds the files to their exact source revision and Tailcat pin. `tailmouse-config.json` selects the current trusted same-origin test deployment.

See the [README](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.1/README.md) for platform selection, checksum commands and a first share. These are unsigned preview binaries; macOS and Windows may prompt before running them.

## Validation and known limits

The release source contains the application code covered by the recorded Linux/macOS full gates, protected Leash/resource browser journeys and four network profiles. Native Windows x64 and ARM64 Go checks passed at 80.5% coverage. The deployed application revision also passed 186 browser cases, with four existing platform-injection skips, and five fuzz targets. [Detailed evidence](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.1/docs/evidence/resource-release-2026-10-19/README.md) identifies the exact revisions and checks; those earlier results are not presented as tests rerun on the release tag.

Publication rebuilds all six native targets with the pinned tools, independently verifies executable metadata, archive contents, licenses, SBOMs and checksums, and executes the extracted Linux x64 binary. The public downloads are checked against the accepted local files. Native execution of every packaged target is not established by cross-compilation.

- Windows Receive, including Dev with Receive, is unsupported. Windows packages are experimental; browser-to-ConPTY end-to-end acceptance is not complete.
- macOS Receive requires an APFS destination and fails closed on unsupported filesystems.
- The Windows Worker fixture cleanup correction remains unverified on native Windows because GitHub Actions was blocked by account billing. The owner authorized direct merge and publication with Actions skipped; this does not turn the deferred check into a pass.
- Physical mobile devices and arbitrary frontend framework versions are not certified. Preview limitations, including cross-origin traffic and Worker WebSockets, are documented in the [resource guide](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.1/docs/resource-sharing.md).
- The current `tailmouse.com` UI and preview share one origin for trusted testing. This does not isolate hostile preview scripts. Terminal access has the host process's permissions, and invitations grant access until revoked or expired.

The hosted browser remains the protocol-compatible build recorded in the deployment evidence. Publishing these native assets does not replace the Cloudflare deployment.
