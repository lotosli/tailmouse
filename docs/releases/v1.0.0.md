# TailMouse v1.0.0

Start with a task: [send files or temporary text in your browser](https://tailmouse.com/#share), or install TailMouse on the host to share a local app or terminal. Guests need only a browser and no account.

## Improvements

- Browser-first onboarding, direct installation commands and current platform guidance.
- Editable file selection with immediate per-file validation, size/count summaries, removal and clearing.
- Locally generated private-link QR codes and the system sharing sheet where supported.
- Actual secure-runtime byte progress, persistent session state, expiry and separate action feedback.
- Capability-aware download limits, file progress, verified completion and deliberate failure retries.
- Explicit replacement-text semantics, UTF-8 capacity, last refresh and unsent draft preservation.
- Retrying platform-aware CLI startup, view-only or input-enabled terminals and visible local management hints.
- Current installation, uninstall, PATH and update recovery documentation; checksum-pinned Homebrew/Scoop recipes.
- The Escape minigame is removed from the CLI, browser, engine, assets, protocol handlers and current tests/build. Historical releases are unchanged.

## Installation and updates

Use the README’s user-local shell or PowerShell installer, or download one of six macOS/Linux/Windows x64/ARM64 archives. Each archive includes the executable, README and notices. Official standalone updates use `tailmouse update`; package-manager installations use their manager. All archives have SHA-256 checksums, per-archive SBOMs and source metadata.

## Actual limits

The 1.0 version is owner-directed. Packages remain unsigned; no signing/notarization identity was available for this release. Windows Receive/Dev with Receive remain unsupported; macOS Receive requires APFS. Cross-build verification does not establish execution on every target OS. Native Windows Worker/ConPTY end-to-end confirmation and physical mobile background continuity remain unverified. Release evidence records actual Linux/public acceptance instead of treating historical runs as fresh validation.

Keep both browser pages open. Sessions default to one hour and one visitor. Selected files are limited to 256 MiB each, 1 GiB reserved transfer traffic, 100 attempts and two active transfers. Browsers without streaming save support have a 64 MiB download ceiling. Text is one session-memory value up to 16 KiB; updates replace it, and nothing executes or writes the clipboard automatically. Sent bytes do not prove the visitor saved a file.

The current tailmouse.com UI/preview share one origin for trusted apps. Tailcat remains pinned; no new service, account system, analytics or dependency was introduced. The four representative Leash network profiles remain the network acceptance scope.

See README and current-main `docs/evidence/native-release-v1.0.0/` for exact source, publication, download and deployment results. Independent user-study results are not claimed.
