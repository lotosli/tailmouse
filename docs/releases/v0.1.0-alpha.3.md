# TailMouse v0.1.0-alpha.3

Share files and text with a browser, or start directly from [tailmouse.com](https://tailmouse.com/#share) with no installation on either device.

## New workflows

- `tailmouse send report.zip`: offer one file for verified download.
- `tailmouse files ./dist`: browse and download a read-only directory.
- `tailmouse text "hello"`, or pipe UTF-8 stdin: exchange temporary text without clipboard or shell automation.
- Browser sharing: select files or text, share the private link and keep the hosting page open. Sessions are encrypted and business data is not stored on the static website server.
- Run `tailmouse` in a terminal for guided startup. Explicit terminal sharing asks before starting the selected program.
- Install with the user-local shell/PowerShell script, Homebrew tap or Scoop bucket. `tailmouse update` verifies the official archive checksum before replacing a standalone installation; `--check` only checks Latest.

Configuration remains optional. Existing CLI/Web/Receive/Dev, Escape, protected Leash and the pinned Tailcat revision remain available. Six archives support Linux, macOS and Windows on x64/ARM64. Each includes the executable, README and notices; checksums, per-archive SBOMs and a source manifest accompany the release.

## Limits

Files are read-only and confined to selected content; hidden/symlink/special entries are omitted. Download defaults are 256 MiB per file, 1 GiB cumulative traffic, 100 attempts and two active transfers. Directory pages contain up to 40 entries, with a 10,000-entry ceiling. Text is limited to 16 KiB. Browser-host sessions expire after one hour and accept one visitor at a time. Browsers without a streaming save picker can download up to 64 MiB through a bounded Blob fallback. Closing or background-suspending a browser can interrupt transfers. A closed host page requires a fresh session.

These remain unsigned alpha packages, presented as non-prerelease Latest at the owner's direction. Windows Receive/Dev with Receive remain unsupported; macOS Receive requires APFS. Linux acceptance and six-target cross-build checks do not establish execution on every target OS/device. The existing same-origin hosted preview remains for trusted applications. Earlier native-platform evidence is preserved without claiming it was rerun for this update.

See the [README](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.3/README.md) for installation and the [resource guide](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.3/docs/resource-sharing.md) for protocol, storage and permission boundaries. Newer publication evidence on main records the actual release and website identities.
