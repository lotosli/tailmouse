# TailMouse v0.1.0-alpha.2

Start sharing with built-in tailmouse.com settings. No local configuration download, account or guest installation is required:

```sh
tailmouse web 8080
tailmouse cli -- sh
mkdir -p ./uploads
tailmouse receive ./uploads
```

Dev combines resources: `tailmouse dev --web 5173 --receive ./uploads -- sh`. Use a program installed on your host; Windows can use `powershell.exe` for CLI sharing. Port-only Web targets use `127.0.0.1` on the sharing machine.

## Changes

- All four resource commands select the existing hosted deployment without a local configuration file.
- Optional TOML/JSON, environment and flag overrides remain supported. Custom origins retain strict validation; missing or malformed explicit files fail instead of silently falling back.
- Homepage, CLI help and README show short commands and the matching downloads.
- Escape, legacy protected Leash, Resource protocol 2, session limits and Tailcat `52fbad323e9d352f1febb623e0975368e9a8cbdd` are retained.

## Downloads and compatibility

Six archives cover Linux, macOS and Windows on x64 and ARM64. Each includes the executable, README, license and notices. `SHA256SUMS`, per-archive CycloneDX SBOMs and the source/asset manifest accompany the downloads. The optional `tailmouse-config.json` asset is for explicit configuration or older clients; normal hosted use no longer needs it. Upgrade from alpha.1 to use the short commands.

These remain unsigned alpha binaries, published as Latest at the owner's direction. Windows support is experimental and excludes Receive, including Dev with Receive. macOS Receive requires APFS. Native execution of every cross-built target, final Windows Worker fixture acceptance and physical mobile-device support remain unverified; earlier platform checks are historical evidence, not reruns of this update.

The hosted interface and preview share tailmouse.com and are for trusted apps. Custom untrusted previews need the documented separate-origin deployment. Terminal access uses the host process's permissions, and the sharing link grants access until revocation or expiry. [README](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.2/README.md) and [resource guide](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.2/docs/resource-sharing.md) contain the complete usage and limits.

Release validation covers configuration defaults and precedence, a configuration-free startup through the CLI composition, the existing full Linux gate, six-target archive/inventory verification and public downloads. Build records bind the checks to their source revisions; cross-compilation alone is not an all-platform execution claim.

[Full Linux gate evidence](https://github.com/lotosli/tailmouse/blob/v0.1.0-alpha.2/docs/evidence/native-release-v0.1.0-alpha.2/full-gate.json) records the tested source hashes, coverage and browser/network results.
