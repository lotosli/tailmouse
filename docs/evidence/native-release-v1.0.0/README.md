## Actual limits

Archives are unsigned. Cross-build validation does not establish execution on every target; native Windows Worker/ConPTY end-to-end confirmation and physical mobile background continuity remain unverified. Windows Receive/Dev with Receive is unsupported; macOS Receive requires APFS. Same-origin previews remain for trusted apps. Browser hosting needs both pages open, with a 64 MiB fallback download ceiling without streaming save support. Tailcat stays pinned at `52fbad323e9d352f1febb623e0975368e9a8cbdd`.

[Vulnerability analysis](vulnerabilities.log) reports zero affected calls/imported packages and six required-module-only findings; it is not a claim of zero dependency findings. Independent user-study results and provider recovery-copy erasure are not claimed. [Topics](topics.json) remains the sole blocked metadata item: GitHub rejects the configured integration with HTTP 403 and requires administration=write, despite the account's administrator role. No additional permission was needed for release publication or either deployment.
